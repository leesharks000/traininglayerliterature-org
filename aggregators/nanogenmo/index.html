NaNoGenMo

https://nanogenmo.github.io/

Writing for the machine readeractive
The archive's reading. The archive reads NaNoGenMo as machine composition at scale in the procedural column of #186 (writing through the machine): each novel is shared with its code under a participant's account, so the generating program is readable, while the attribution of the generated text and of any source novel it draws on is left to the participant ('ultimately it's on your head').
Kindan annual month-long activity: write code that generates a novel of 50k+ words, organised as a community on GitHub
Operatorits official admins @dariusk and @hugovk; the community is organised in GitHub repositories, one per edition; based on an idea Darius Kazemi tweeted
Evidenceevent archive
Unit of recorda participant's issue on an edition's repository, declaring intent and carrying dev diaries, sample output, at least one generated novel and its source code
What it recordscode-generated novels of 50,000 words or more and their source code, shared by participants each November since 2013
In the layernot recorded; the rules allow a 'novel' made from existing text (it 'could literally grab a random novel from Project Gutenberg') and point to corpora, a repository of public domain lists
Under whose namea participant declares intent in an issue under their own GitHub account; the saved page states no rule on how a generated novel is credited, and the source code 'does not have to be licensed in a particular way'
Found and read backeach edition's repository issues, with a resources issue per edition, 2013 to 2025
Methodopen participation: a participant opens an issue on the edition's repo, works through November, and shares at least one novel and the source code
Coveragegeography: not recorded (an online community); period: editions 2013 to 2025 listed; each runs 12:01am GMT November 1 to 12:01am GMT December 1
Countvalue: 13 editions listed (2013 to 2025); as_of: 2026-11-01 (home page read; no 2026 edition listed)
Holdingseditions 2013 to 2025; a resources issue for each edition (libraries, corpuses, APIs, techniques); sister events NaPoGenMo, NaOpGenMo and NaMoGenMo

Founded2013

What its record can settle

  • who declared participation in an edition and what novel and code they shared
  • what resources participants pooled for each edition

What it cannot settle

  • whether any generated novel or its source text is in a training corpus or a model
  • the authorship or licence of a generated novel (no rule stated)
  • how many participants or novels any edition had (not stated)

Kept apart

  • NOT National Novel Writing Month: it borrows NaNoWriMo's definition of a novel as 50,000 words of fiction
  • NOT a curated anthology: the only rule is sharing a novel and its code
  • NOT an AI or LLM project by its own statement: the rules name code, with the novel 'defined however you want'
  • NOT a copyright authority: it states it will not police copyright

Relations

  • neighbour: Project Gutenberg (the rules give grabbing a random novel from Project Gutenberg as an allowed 'novel')
