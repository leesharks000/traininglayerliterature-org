The training layer: a meta-aggregator

A census of the corpora that carry writing into machine training, the tools and methods that test whether a work is there, and the literature written for the machine reader: electronic literature, data poetics, generative and computational writing. Each resource is read from its own pages. Every field is quoted from a saved copy of the resource's own pages, with the date read and a hash of the copy. Compiled 2026-11-01; editor Lee Sharks.

The census asks of each resource: Is the work in the layer, under whose name, and can it be found there and read back?

The question joins two deposits: Who Is Writing for the Machines? Training-Layer Literature: A Field Survey (AXN:032C, #186), the field survey of writing addressed to the machine reader, and Generative Uptake: Training-Layer Literature Extended from Machine Reading to Machine Composition (EA-TLL-COMPOSITION-01) (AXN:0642, #1543), which extends the genre from machine reading to machine composition. A work written for the layer meets three facts in each resource below: whether the work is held there, whether its author's name travels with it, and whether anyone can find it there and read it back. This census records which resources show each.

Its sibling census, on authorship and the names authors choose, is the apparatus meta-aggregator at leesharks.com; the family's other censuses are Labor Vector (labor and AI) and Mary Lee Labor (left politics and labor).

The corpora: collections, crawls and datasets whose texts enter machine training

Common Crawl

free, open repository of web crawl data · the Common Crawl Foundation, a 501(c)(3) non-profit founded in 2007; Wikipedia names Gil Elbaz as founder and Rich Skrenta as executive director

Project Gutenberg

online library of free eBooks · the Project Gutenberg Literary Archive Foundation, which operates Project Gutenberg and accepts donations; per Wikipedia, a 501(c)(3) chartered in Mississippi in 2000, with Eric Hellman acting CEO after Gregory Newby died in 2025

Found and read back: each eBook has a permanent landing page; site search; a Gutenberg index file listing all books and a machine-readable catalog database (Offline Catalogs and Feeds); the website itself 'is intended for human users only', and bulk downloads go through mirrors

Internet Archive

non-profit digital library (Wikipedia's description; the own about page saved no text) · the Internet Archive, an American 501(c)(3) non-profit library founded in 1996 by Brewster Kahle, headquartered in San Francisco (per Wikipedia; its own about page was unread)

HathiTrust Digital Library

large-scale collaborative repository of digital content from research libraries (Wikipedia's description) · HathiTrust, a university consortium of more than 219 research libraries (2024) under shared governance, administered by the University of Michigan; executive director Mike Furlough (per Wikipedia; the own about page was refused)

The Pile

open source language modelling data set: an English text corpus targeted at training large-scale language models · EleutherAI (the home page footer reads 'EleutherAI 2021'; the paper's authors are Leo Gao and 11 others)

Dolma

an English corpus for language model pretraining research, released with its documentation and an open-source data curation toolkit · the paper's 36 authors, Luca Soldaini and 35 others (arXiv:2402.00159); the dataset card sits under the allenai namespace on Hugging Face, and its text was rate-limited (HTTP 429) and is unread, so the saved sources name no institution

Finding a work in the layer: tools and methods that test whether a work is in a training set or in a model

Min-K% Prob

a detection method for pretraining data, introduced in a research paper together with a dynamic benchmark, WIKIMIA · the paper's eight authors: Weijia Shi, Anirudh Ajith, Mengzhou Xia, Yangsibo Huang, Daogao Liu, Terra Blevins, Danqi Chen, Luke Zettlemoyer; the code repository (swj0419/detect-pretrain-code) is unread
Finding a work in the layerhistorical
Found and read back: a membership test from outside the model: 'given a piece of text and black-box access to an LLM without knowing the pretraining data, can we determine if the model was trained on the provided text?'; it needs no knowledge of the corpus and no additional training

Speak, Memory: An Archaeology of Books Known to ChatGPT/GPT-4

research paper: a data archaeology of the books known to ChatGPT and GPT-4 · the paper's four authors: Kent K. Chang, Mackenzie Cramer, Sandeep Soni, David Bamman
Finding a work in the layerhistorical
Found and read back: a membership inference from outside the model: a name cloze query infers which books the model knows; the paper argues for 'open models whose training data is known'
